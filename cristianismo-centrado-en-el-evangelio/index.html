Cómo usar esta página

Lee en línea o imprime para el grupo

Cada estudio tiene una página pública para leer en celular, tableta o computadora. La página mantiene el flujo de la lección: introducción, concepto clave, implicaciones, estudio bíblico y preguntas.

Cuando necesites papel, abre la versión para imprimir. Está pensada como una hoja limpia para participantes, sin notas internas.

Ruta recomendada

Comienza con la página pública. Usa la versión para imprimir cuando vayas a enseñar o compartir el estudio en grupo.
